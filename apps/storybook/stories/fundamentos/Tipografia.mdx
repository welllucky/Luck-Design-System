# Tipografia

**Manrope** 400–800 para texto; títulos em 700 com tracking de −0.045em no display e −0.03em nos títulos. **JetBrains Mono** para legendas, índices, tags e metadados (11–12 px, maiúsculas, +0.06em). As fontes são auto-hospedadas em `@welllucky/luck-styles`.

| Classe          | Uso                                                        |
| --------------- | ---------------------------------------------------------- |
| `.luck-display` | Chamada principal do hero                                  |
| `.luck-h1`…`h4` | Hierarquia de títulos                                      |
| `.luck-lead`    | Parágrafo de abertura                                      |
| `.luck-body`    | Texto corrido                                              |
| `.luck-small`   | Texto de apoio                                             |
| `.luck-eyebrow` | Legenda numerada em mono: `01 / CONTATO E REDES SOCIAIS`   |
| `.luck-mono`    | Metadados e índices                                        |
| `.luck-accent`  | Ênfase âmbar na segunda parte do título                    |

**Títulos em duas partes:** chamada + ênfase em âmbar. **Sem emoji.** Separador `·`; setas vêm dos ícones.
